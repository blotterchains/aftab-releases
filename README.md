Aftab (Aftab Panel) is an Android database panel built for anyone managing MySQL, PostgreSQL, SQLite, MongoDB, or an SSH server who doesn't want to open a laptop just for a quick look.

Save your connections, browse tables and collections, edit rows and documents, run commands in the console, log into your server via SSH, and use the same Google account for both Google Drive backups and asking the Gemini assistant.

What It Does
- MySQL, PostgreSQL, SQLite (.db / .sqlite files or internal app databases), and MongoDB
- Dedicated forms for each connection type: host and port, SQLite file, or SSH server with password or private key
- Table and collection lists, pagination, row editing, and document editing
- SQL console and MongoDB JSON commands on saved connections
- SSH terminal with multiple concurrent tabbed sessions, touch shortcut keys, and host key pinning (the session disconnects if the server key changes)
- Home screen displaying Google account status alongside a list of recently opened connections and servers
- On-device CSV export, plus Google Drive backup, restore, and merge with a single sign-in
- Gemini assistant using the same Google sign-in, with no API key setup required: reads database schemas, searches across connections, and suggests schemas before you build a project
- Real system error reporting in app messages (HTTP status, Google reason, SQL or network error) complete with a copy button for troubleshooting
- Light and dark themes. Both the status bar and bottom navigation bar match the active theme instead of staying as a separate black bar
- 16 languages, including Persian, Arabic, and Urdu with full right-to-left (RTL) layout. On Android, the app language follows the system language (or per-app language settings on Android 13+) and updates immediately when you change your phone's language. You can also select the language manually right next to the theme toggle

Who It's For
- Backend developers and anyone checking server databases from their phone
- Students and anyone learning SQL, MongoDB, or server administration
- Teams managing multiple databases who want a single mobile app instead of phpMyAdmin, Adminer, DBeaver, or MongoDB Compass

Privacy
- Your Google sign-in, tokens, and connections stay locally on your device
- Google Drive backup only accesses files created by Aftab itself (drive.file)
- To export files to the Downloads folder, simply grant Android file permission once

Install Aftab to keep MySQL, PostgreSQL, SQLite, MongoDB, and SSH right at your fingertips—in your phone's language and in light or dark mode.
